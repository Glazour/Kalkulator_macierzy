# Kalkulator_macierzy
Projekt kalkulatora macierzy, póki co jesteśmy w stanie z nim tworzyć macierze różnego typu, a następnie mnożyć, dodawać i odejmować je od siebie. 
Jeśli chcemy wyliczyć punkt po transformacji, musimy najpierw dać mnożenie wszystkich macierzy w ODWROTNEJ kolejności, czyli jak mamy najpierw obrót, potem przesunięcie i potem odbicie to robimy odbicie, przesunięcie, obrót, a na końcu macierz punktów (np. dla punktu -6,7 będzie to 1 kolumna, 3 wiersze -6, 7, 1)
Kalkulator może również rozwiązywać równania macierzowe, pod warunkiem, że niewiadoma nie jest mnożona z dwóch stron.
